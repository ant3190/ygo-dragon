# 对战操作与 WindBot 接入

## 操作契约

| 场景                      | 左键                                     | 右键 / Esc           | 确认                                                          |
| ------------------------- | ---------------------------------------- | -------------------- | ------------------------------------------------------------- |
| 普通行动                  | 点卡片，展开贴近卡片的行动菜单           | 关闭菜单             | 选择明确的召唤、发动、攻击等行动                              |
| 普通对象 / 卡片多选       | 点选；再点一次撤回                       | 撤回最近一张         | 数量和求和条件满足后统一确认；单选也不自动提交                |
| 融合 / 链接等连续素材选择 | 所有更改先留在本地草稿，可多选           | 撤回最近一次更改     | 按「确认素材」后，服务器按最新合法候选逐步提交                |
| 素材条件变化              | 根据新的合法候选调整                     | 可撤回已选素材       | 停止旧草稿，不自动确认不完整组合                              |
| 全部取消素材              | 点「取消」或「重选」                     | 不把 -1 当作通用取消 | 先撤回核心已接受的素材，再在规则允许时取消；-1 可能意味着完成 |
| 放置区域                  | 点场上高亮区域                           | 撤销区域选择         | 按确认后放置                                                  |
| 墓地 / 除外 / 额外        | 直接列出已知卡片；点卡查看或选择行动     | 关闭列表             | 不播放逐张翻面；浏览本身不提交选择                            |
| 阶段                      | 点右侧阶段按钮，选择下一阶段             | 关闭阶段菜单         | 结束回合按设置二次确认                                        |
| 连锁                      | 自动 / 全时点 / 跳过；按住左键临时全时点 | 按住右键临时跳过     | 简洁询问；不重复展开整张效果                                  |

浮层返回顺序为：卡片详情、对战菜单、区域列表、阶段菜单、卡片行动、最近一次选择、规则允许的取消。Enter 提交当前有效的选择；输入框中的 Enter 不触发对战操作。断线、动画或提交期间锁定响应，规则错误恢复当前选择，不结束对局。

所有候选都在场上时，默认收起候选图册，保留底部确认条，避免遮住要点的素材。图册可手动展开；来自手牌、卡组、墓地、额外的候选按双方和来源分组，蓝色为我方、红色为对方，支持横向滚轮。

## 真实的 MDPro3 单人模式

核对的 MDPro3 源码使用本地 YGO 服务和 WindBot 进程进行单人对战，并非一个对匿名网页开放的专用“单人服务器”。MyCard 登录流程的对战端点需要其会话信息，不能直接假装匿名登录已成功。

本项目通过服务端 WebSocket 适配 YGOPro 0x1332 / 4962 协议，默认连接 `wss://koishi.momobako.com:7211` 的兼容 WindBot 服务。服务器在 `.env` 的 `YGO_AI_SERVER` 配置，协议版本由 `YGO_AI_VERSION` 配置。浏览器只连接本项目；上游连接由本地房间持有，浏览器短暂重连不会另建 AI 对局。

对手列表来自 MDPro3 中文 `bot.conf` 中可按 Deck 调用的配置，并增加随机对手，共 44 项。经典「我太帅了-真红眼龙骑士」对应 `/ai Dragun`；按 Deck 调用避免服务端中文昵称变化导致找不到对手。实际服务端昵称会显示在对局中，可能与列表别名不同。未提供可在线调用 Deck 的“指定本地卡组文件”选项不列入。

开局依次完成建房、提交出战卡组、邀请指定 AI、准备、猜拳与选择先后手。卡片/素材/区域响应、连锁、卡片查询、移动和 LP 变化统一转换到前端操作模型。上游拒绝卡组、对手不存在、版本不符或断线时显示具体错误，不悄悄换成基础练习策略。

「离线基础练习」为独立的可选入口，使用本地规则核心与简单策略；界面明确显示其身份。

## 验证范围

单元和本地 WebSocket 集成测试覆盖分包/粘包、指定 Deck 调用、猜拳、先后手坐标转换、隐藏信息、多选、连续撤销、固定素材脚本及条件变化。真实核心自动对局和双人房间检查另行运行。

浏览器中已实际验证：召唤/盖卡、区域确认与右键撤回、天使的施舍双选弃牌、候选窗收起后的场地选卡、连接蜘蛛固定素材确认、链接后的特殊召唤与守备方向、阶段二次确认和连锁结算。

公网已验证握手、建房、`/ai Dragun` 邀请及完整结算：固定公开测试卡组对战 5 回合、18 次合法响应，服务器昵称为「蓝叶雾叶」。脚本 `scripts/smoke-ai.mjs` 不读取已保存卡组、玩家档案或个人文件。其余对手的可用性由服务器实际安装的配置决定。
