# 视觉与交互规范 · 0.3

界面围绕卡组、对手和实际对局组织。大厅只保留出战卡组、单人/联机入口和卡组快捷切换。移除营销标语、英文装饰标签、资源统计大卡片、重复入口与整页侧栏。

底色采用冷调深灰，内容表面逐级提亮。默认强调色为低饱和灰蓝；蓝/红的选择状态分别表示我方和对方。按钮通过深色曲面、上缘微光、柔和阴影、悬停提亮和按压内陷建立材质；输入框是深色凹面。普通按钮不使用黑色轮廓加浅色填充。焦点描边和选卡高亮只承担明确的操作反馈。卡组编辑、对手选择、设置和对战共用同一套表面、字重和圆角尺度。

对战按 neos-ts 的区域关系建立七列五行网格：中央五列是双方怪兽与魔陷区，中间行放共享额外怪兽区；外侧两列容纳卡组、额外、墓地、除外和场地卡。双方镜像排列，我方除外在墓地上方，额外在左下、卡组在右下。不使用透视、扇形手牌或装饰背景图。对方手牌保持完整卡牌比例和平直排列，使用统一深蓝卡背；我方手牌不抬起、不因悬停重排。

卡片信息在左，双方 LP 分居左下/右上；六阶段快捷按钮和连锁控制放在独立右栏，当前阶段与可切换阶段分别标识。行动菜单贴近所点卡片。全部候选都在场上时，默认使用底部确认条；候选来自卡组、额外或墓地时才展开列表。可随时收起列表，直接点场地选择。窄屏收起详情栏时保留独立菜单、卡片详情和记录入口；更窄时阶段与连锁操作移到底部，避免挤进场地。

素材选择先在界面中暂存，按「确认素材」后才依次提交给规则核心。固定素材数脚本即使在最后一次选择后自动继续，也不会跳过用户确认。右键先返回当前浮层，再撤销最近一次选择；全部取消独立于最终确认。详见 [操作契约](interaction.md)。

卡片移动使用稳定身份和前后位置进行插值，旋转与平移分开处理；按事件顺序播放抽卡、移动、连锁和 LP 变化。召唤没有二次抬起/放下；抽卡和检索不作装饰性手牌重排，核心的洗牌更新只更新状态。支持正常、快速和关闭动画，并尊重系统减少动态效果设置。

## 研究资料

以下资料用于识别模板化设计和分析信息层级，不作为必须照抄的规则，也不复制其素材：

- [StyleKit 风格库](https://www.stylekit.top/zh/styles)：按用户指定参考暗色层次和表面材质；参考 [Dark Mode](https://www.stylekit.top/zh/styles/dark-mode)、[Neumorphism](https://www.stylekit.top/zh/styles/neumorphism) 与 [macOS Vibrancy](https://www.stylekit.top/zh/styles/macos-vibrancy)，将高光、阴影与半透明浮层收敛到操作需要的范围。
- [neos-ts 场地布局](https://github.com/ant3190/neos-ts)：核对现有项目中的 `src/ui/Duel/layout/geometry.ts`，参考双方镜像区域、共享额外怪兽区、卡牌比例和平铺手牌。
- [no-slop-ui](https://github.com/LeoStehlik/no-slop-ui)：识别通用巨幅标语、嵌套面板、无关统计、英文小标签等模式。
- [Slop Patterns](https://subclaude.com/slop/)：检查装饰是否服务于实际任务。
- [Impeccable](https://github.com/pbakaus/impeccable)：界面层级、排版和具体的设计取舍。
- [Master Duel UI 设计分析](https://note.com/togetogedesign/n/nd49bef3af6da)：卡片文本、系统一致性和对局操作的设计观察。
- [Master Duel 实机画面](https://vtubernewsdrop.com/content/images/2023/01/20230113230205_1.jpg)：用于对照信息分布；本项目不分发该截图或游戏演出素材。
- [MDPro3 源码镜像](https://github.com/SethPDA/MDPro3)：查看真实的左右键、场上选卡、素材与 WindBot 流程。
