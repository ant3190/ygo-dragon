# YGO Dragon 视觉与交互

界面采用深色系，安静、有层次，避免大幅装饰插画、全屏霓虹、粒子背景与持续运动。卡图是主要的视觉内容。背景可使用低对比渐变与细微表面层次，不局限于纯色。

- 石墨灰 / 墨蓝：页面、面板、浮层逐级提亮，以边界与间距区分内容。
- 低饱和青绿：主要操作与选中状态；我方蓝色、对方红色用于场地归属。
- 统一线性图标，正文 14–16px，重要操作至少 44px，键盘焦点清晰。
- 大厅以排版与实用入口建立层次；编辑器以卡图网格为主；对战以场地为主。
- 不使用透视场地、扇形手牌、抽卡后二次抬起、洗手牌或装饰性洗牌动画。
- 卡片选择先选择再确认，支持多选、取消、右键清空；连续素材选择保留同一面板，最后统一确认。
- 连锁提示简洁，不重复展开整段效果；自己的检索不增加确认弹窗。
- 动效只说明位置与状态，尊重系统减少动态效果设置。
