# 视觉与交互规范 · 0.4

界面围绕卡组、对手和实际对局组织。大厅只保留出战卡组、单人/联机入口和卡组快捷切换。移除营销标语、英文装饰标签、资源统计大卡片、重复入口与整页侧栏。

底色采用冷调深灰，内容表面逐级提亮。默认强调色为低饱和灰蓝；蓝/红的选择状态分别表示我方和对方。按钮通过深色曲面、上缘微光、柔和阴影、悬停提亮和按压内陷建立材质；输入框是深色凹面。普通按钮不使用黑色轮廓加浅色填充。焦点描边和选卡高亮只承担明确的操作反馈。卡组编辑、对手选择、设置和对战共用同一套表面、字重和圆角尺度。

对战按 neos-ts 的区域关系建立七列五行网格：中央五列是双方怪兽与魔陷区，中间行放共享额外怪兽区；外侧两列容纳卡组、额外、墓地、除外和场地卡。主场区采用平直方格、低对比填充与细边线，取消圆角凹槽、渐变内阴影和重复区域编号。墓地、除外和场地卡使用较小的竖向卡槽，卡片大小与主场区协调。双方镜像排列，我方除外在墓地上方，额外在左下、卡组在右下。不使用透视、扇形手牌或装饰背景图。所有里侧卡使用经典棕色旋涡卡背；我方手牌不抬起、不因悬停重排。怪兽守备横向显示，盖放魔陷保持竖向。

可执行普通召唤、盖放、攻击或改变表示的卡片显示蓝色边框；可发动效果或特殊召唤的卡片显示金色边框，后者优先。判断直接来自当前规则提示，不根据卡片类型猜测；手牌、场上、额外/墓地卡堆和浏览列表均使用同一规则。无合法行动时立即撤掉边框；颜色之外提供可操作文字、说明和固定图例。

猜拳与先后手使用独立准备页。三个手势先选中、再确认，等待双方揭晓；平局显示结果后重新选择，胜方进入先后手选择。出拳编码、胜负和先后手来自真实 YGOPro 协议与服务器消息，不在前端随机决定。连接、等待、结果和开始对局各有明确状态。

卡片信息在左，双方 LP 分居左下/右上；六阶段快捷按钮和连锁控制放在独立右栏，当前阶段与可切换阶段分别标识。行动菜单贴近所点卡片。全部候选都在场上时，默认使用底部确认条；候选来自卡组、额外或墓地时才展开列表。可随时收起列表，直接点场地选择。窄屏收起详情栏时保留独立菜单、卡片详情和记录入口；更窄时阶段与连锁操作移到底部，避免挤进场地。

素材选择先在界面中暂存，按「确认素材」后才依次提交给规则核心。固定素材数脚本即使在最后一次选择后自动继续，也不会跳过用户确认。右键先返回当前浮层，再撤销最近一次选择；全部取消独立于最终确认。详见 [操作契约](interaction.md)。

卡片移动使用稳定身份与前后位置，在独立图层插值飞行，到达后恢复目标卡片；旋转与平移分开处理。服务端与前端共用演出时长，不再因队列积压压缩成 70ms。抽卡有短错开移动，召唤与发动有卡片边缘扩散提示，连锁结算、攻击和 LP 变化按真实事件顺序播放。召唤后不再抬起/放下；已有手牌不作装饰性重排，洗牌只更新状态。正常、快速和关闭动画以及系统减少动态效果均受到支持，动画结束/取消/卸载时清理临时图层。实机连续过程见 [动画录屏](animation.mp4)。
