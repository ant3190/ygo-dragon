# 视觉与交互规范 · 0.2

界面围绕卡组、对手和实际对局组织。大厅只保留出战卡组、单人/联机入口和卡组快捷切换。移除营销标语、英文装饰标签、资源统计大卡片、重复入口与整页侧栏。

底色采用暖石墨灰，内容表面逐级提亮；低饱和砂金用于主要操作。蓝/红只表示我方和对方。以文字、细分隔线、卡图和间距建立层次，不使用装饰背景图、霓虹、玻璃光团或粒子。按钮与字段沿用统一尺寸和字重。卡组编辑、对手选择、设置页共用同一套基础样式。

对战采用平面五列场地、共享额外怪兽区和平铺手牌。卡片信息在左，双方 LP 分居左下/右上；阶段与连锁控制在右侧。行动菜单贴近所点卡片，避免视线跨越整个场地。全部候选都在场上时，默认使用确认条；候选来自卡组、额外或墓地时才展开列表。可随时收起列表，直接点场地选择。

素材选择先在界面中暂存，按「确认素材」后才依次提交给规则核心。固定素材数脚本即使在最后一次选择后自动继续，也不会跳过用户确认。右键先返回当前浮层，再撤销最近一次选择；全部取消独立于最终确认。详见 [操作契约](interaction.md)。

卡片移动使用稳定身份和前后位置进行插值，旋转与平移分开处理；按事件顺序播放抽卡、移动、连锁和 LP 变化。召唤没有二次抬起/放下；抽卡和检索不作装饰性手牌重排，核心的洗牌更新只更新状态。支持正常、快速和关闭动画，并尊重系统减少动态效果设置。
